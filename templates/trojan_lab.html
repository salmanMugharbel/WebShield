Malware protection · Trojan horse

Stopping malicious code disguised as a harmless file

A Trojan horse is malware that pretends to be something legitimate, such as an invoice, a photo, a document or a software update, so that the victim or the server lets it in. Unlike a virus it does not copy itself; it relies on deception. WebShield protects against Trojans in two places: every uploaded file passes eight independent checks, and the application's own code is watched by a SHA-256 integrity monitor.

Disguised executablesholiday.jpg that is really a program; checked by magic bytes.
Hidden extensionsinvoice.pdf.exe and right-to-left override names.
Macro documentsWord files carrying VBA macros that run when opened.
Tampered codeBackdoors added to the app itself; caught by the integrity monitor.

2 Source code integrity monitor

A Trojan can also be planted inside the application itself, for example a hidden backdoor added to the login code by an attacker or a compromised update. WebShield stores a trusted SHA-256 baseline of every source file (security/integrity_manifest.json), checks it at every start-up and on demand here. The baseline can only be rebuilt from the command line by the developer, never from the website.
