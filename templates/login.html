How this login is protected

user = db.execute(
    "SELECT id, username, password_hash "
    "FROM users WHERE username = ?",
    (username,)).fetchone()

if user and check_password_hash(
        user["password_hash"], password):
    session.clear()      # prevent fixation
    session["user_id"] = user["id"]
  • The ? placeholder keeps input as data — it cannot change the SQL.
  • Passwords are compared against a salted scrypt hash, never stored in plaintext.
  • The same error message is shown for unknown users and wrong passwords.
  • The session cookie is HttpOnly, SameSite=Strict and expires after 30 minutes.
